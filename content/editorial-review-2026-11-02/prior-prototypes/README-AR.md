## هذه الحزمة ليست موقعًا بديلًا

الدفعة مصممة لدمج **نصوص تحريرية حقيقية** في صفحات بيت الريف الحالية باستخدام مكون React خفيف. لا تحتوي صفحات HTML مستقلة، ولا تعديلات على GitHub أو Cloudflare أو Supabase، ولا صلاحيات للوصول إلى Source مشروع ChatGPT Site، ولا ادعاء بنشر شيء.

## الملفات المنفذة

- `content/ar/uae-expert-guide.md`: أصل محرر للمستوى الوطني بمراحل البناء والتوثيق والاختيار والرقمنة والتسعير والمناقصات وحقوق الأطراف.
- `content/ar/abu-dhabi-construction.md`: أصل محرر للإمارة، وفيه دور الاستشاري وتصنيف المهندسين والمقاولين الرسمي واستكمال المشاريع المتوقفة.
- `content/ar/alain-operations.md`: أصل محرر لمشكلات فعلية في خدمات العين وطلبات العميل قبل المعاينة، دون ادعاء أرقام محلية.
- `content/ar/aljimi-coverage.md`: أصل محرر لتغطية الجيمي وتصحيح الخلط بين مقر الشركة ومناطق الخدمة.
- `content/ar/water-leakage-technical.md`: دليل تفصيلي للتسرب والفحص والإصلاح والتسعير والاستلام.
- `content/ar/kitchen-custom-product.md`: دليل طلب مطبخ حسب المقاس يتصل بكيان المنتج نفسه، وليس إعادة إنشاء منتج.
- `content/ar/tender-rfq-workflow.md`: نص تنفيذ عملي لطلب السعر والمناقصة والفحص والترسية الآمنة.
- `docs/engineering_and_maintenance.json`: معلومات فنية متخصصة لـ15 فرع استشارات و22 فرع صيانة، كل منها بمعايير مختلفة، لكنها ليست بعد مقالًا معمقًا كاملًا لكل تخصص.
- `components/BietAlreefKnowledge.jsx` + CSS Module: مكون متحفظ لإضافة المحتوى داخل صفحة موجودة بعد موافقة التحرير. لا يغير قالب الموقع العام ولا H1 الأساسي.
- `data/weyaakRequirements.mjs`: فحص اكتمال معلومات عرض السعر وتحديد حقول مختصة لكل ستة أنواع من الأعمال؛ لا إجراء شبكي أو كتابة.
- `data/weyaakWorkflowDecision.mjs`: موجه مبدئي بين البحث وRFQ والمناقصة وRFI وشراء المنتج، بلا أذونات أو تنفيذ فعلي.
- `tests/validate.mjs` و `tests/weyaak.test.mjs`: فحص جودة النصوص الأساسي والهيكلة والسلوك الحذر.

## طريقة الدمج بعد توفير source المشروع الصحيح

استخدم المفتاح `uae` فقط في المكون المنشور فعليًا للصفحة العربية `/uae`، وهو `DirectoryLandingPage.js` وفق أحدث فحص سابق. تتم الإضافة *داخل الصفحة الأصلية مع بطاقة الشركات والبحث والملاحة القائمة*، وليس استبدالها.

```jsx
import BietAlreefKnowledge from './BietAlreefKnowledge';

// In existing DirectoryLandingPage.js where public directory content belongs:
// <BietAlreefKnowledge contentKey="uae" locale={locale} editorialApproved={true} />
```

يجب تعديل مسار الاستيراد وفق الملفات الحقيقية؛ هذه **تعليمة دمج وليست Patch مطبقًا**. لا تضف H1 جديدًا، ولا تضف `noindex` أو تغير canonical أو بطاقات الشركات بهذه العملية. إن اختلف اسم الملف أو بنية المشروع، عدل الدمج على المصدر الحقيقي لا على افتراضاتنا.

مفاتيح المحتوى المتاحة حاليًا: `uae`, `abu-dhabi`, `al-ain`, `al-jimi`, `water-leakage`, `custom-kitchen`, `tender-rfq`. لا يُستخدم مفتاح منطقة أو خدمة حتى يُطابق مكانها مع المسار الموجود فعلًا؛ **لم نثبت المسار النهائي للجيمي ولا لمسار صفحة تسرب المياه من مصدر الموقع الحالي**. كما أن السوق تطبيق مستقل، ويجب دمج نص المطابخ في مسار عرض المنتج الحقيقي بعد الوصول إلى source السوق.

## بوابة الجودة

- النسخة الحالية **عربية فقط**؛ الإنجليزية لم تُكتب ولم تُعرض، ولذلك لا يجوز اعتبار التغطية ثنائية اللغة مكتملة.
- اختبار المحتوى والكود الخالص لا يساوي اختبار Next.js Build أو دمج الصفحة أو أداء الهاتف أو الفهرسة الفعلية.
- المقالات السبعة نصوص أصلية تحتاج مراجعة تحريرية نهائية، وليست إثباتًا بأن جميع تخصصات الاستشارات والصيانة صارت مقالات موسعة.
- لن تظهر أسماء شركات أو أرقام تراخيص أو أسعار محلية ما لم يثبت المصدر والملف المنشور؛ لا يتم ملء فراغات التصميم ببيانات خيالية.
- لا تُنشئ أسماء دوال Supabase جديدة أو تُطلق تنفيذ مناقصة قبل مراجعة RPC الحالية وصلاحيات المالك والمزود.
- ملفات Search Console المصورة والـ53 رابطًا لم تُعالج هنا؛ يلزم استخراج قائمة الروابط الفعلية ورؤية HTML للموقع الحالي.
- ناتج هذا الإصدار **غير منشور وغير متصل بقاعدة الإنتاج**.
