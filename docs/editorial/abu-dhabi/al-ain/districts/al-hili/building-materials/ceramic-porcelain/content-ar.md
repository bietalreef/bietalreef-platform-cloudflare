# السيراميك والبورسلان — الهيلي، العين

معلومات تحضيرية لمقارنة نطاق أعمال الشركات؛ لا تعني توفر جهة منفذة أو سعر أو موعد.

## 1. توريد السيراميك

تبدأ خدمة توريد السيراميك بفحص موضع الاستخدام والركيزة أو المنتج القائم؛ فقد تختلف متطلبات العمل بين مطبخ أو حمام أو واجهة أو أرضية. يلزم تحديد **المقاس والدرجة والدفعة ومواءمة الجدار أو الأرضية** قبل إصدار سعر قابل للمقارنة، مع صور واضحة وقياسات فعلية ونقاط التقاء الأعمال المجاورة.

**نطاق التنفيذ:** اطلب توضيح ما إذا كان العرض يشمل الرفع الموقعي، العينات، التصنيع أو القص، مواد التثبيت، النقل، الحماية والتنظيف. لا تفترض أن فك القديم أو معالجة الرطوبة أو تقوية القاعدة أو نقل الخدمات ضمن السعر؛ هذه أعمال تحتاج بندًا مستقلًا بعد الفحص. المواد الهشة أو الثقيلة تتطلب خطة مناولة مناسبة واحتياطات سلامة.

**اختيار العرض:** قارن مواصفة الخامة، طريقة التنفيذ، تفاصيل الوصلات والحواف، الهالك والقطع الاحتياطية، مدة التصنيع أو المعالجة، الضمان المكتوب وطريقة التعامل مع العيوب. اربط دفعات السداد بمراحل قابلة للفحص، واعتمد العينة أو المخطط قبل التصنيع.

**الاستلام:** راجع المقاس والدرجة والدفعة ومواءمة الجدار أو الأرضية، والتجانس البصري واستقامة الخطوط وعدم وجود كسر أو فراغات أو حواف حادة، بحسب طبيعة الخدمة. وثّق أي ملاحظة بالصور قبل الإغلاق النهائي. خدمة عملاء بيت الريف تساعد في صياغة طلب عرض السعر وإرساله عند توفر القنوات المناسبة دون ضمان قبول شركة أو موعد.
