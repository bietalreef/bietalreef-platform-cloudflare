# مصانع الخرسانة والطابوق والمنتجات الأسمنتية — الهيلي

قبل شراء خرسانة أو طابوق لمشروع في الهيلي، اطلب المواصفات الهندسية وجداول الكميات من المخطط، فالمادة الصحيحة للموقع ليست بالضرورة الأقل سعرًا للوحدة. حدد التوريد والاختبارات والاستلام قبل الاتفاق.

> وضع التخصص في الشجرة: جديد مقترح. إعداد محتوى الخدمة لا يعني وجود شركة منشورة أو تفعيل تصنيف مقيد.

## 1. تصنيع الخرسانة الجاهزة

حدد درجة الخرسانة والهبوط والمضافات ووقت الصب والظروف التشغيلية وفق تصميم المهندس. عند وصف موقع العمل، أرسل المواصفات الفنية وجداول الكميات ومواقع الصب أو التخزين والوصول إلى الموقع. ضع ملاحظات عن الأجزاء الحساسة وأماكن الوصول حتى يمكن تقدير الجهد المطلوب دون زيادات مفاجئة.

**تفاصيل الاتفاق:** اطلب تحديد درجة المادة والأبعاد والاختبارات المتفق عليها وكميات كل دفعة والنقل والتفريغ ومدة صلاحية العرض. قارن عروضًا لها النطاق نفسه، وحدد المواعيد الممكنة وطريقة الاعتماد ومسؤولية التالف والاستثناءات كتابة. احرص على وضوح ما إذا كان السعر على القطعة أو الرحلة أو اليوم.

**التسليم والفحص:** راجع تذاكر الخلطة وأوقات الخروج والوصول والاختبارات المطلوبة. طابق ملصقات الدفعة وشهادات المطابقة المطلوبة وأخذ العينات وفق خطة المشروع قبل الاعتماد. وثّق النواقص قبل قبول محضر التسليم.

## 2. تصنيع الطابوق والبلوك

## 3. تصنيع المنتجات الأسمنتية

## 4. توريد المنتجات للمشاريع

وزع الكميات على مراحل الإنشاء وراجع سعة التخزين ومواعيد وصول الشاحنات. عند وصف موقع العمل، أرسل المواصفات الفنية وجداول الكميات ومواقع الصب أو التخزين والوصول إلى الموقع. ضع ملاحظات عن الأجزاء الحساسة وأماكن الوصول حتى يمكن تقدير الجهد المطلوب دون زيادات مفاجئة.

**التسليم والفحص:** طابق كل دفعة مع إذن التسليم وقائمة الكميات والاختبارات. طابق ملصقات الدفعة وشهادات المطابقة المطلوبة وأخذ العينات وفق خطة المشروع قبل الاعتماد. وثّق النواقص قبل قبول محضر التسليم.

## خدمة عملاء بيت الريف

تحتاج مساعدة في اختيار الشركة المناسبة؟ أرسل تفاصيل العمل والصور والمقاسات المتاحة إلى خدمة عملاء بيت الريف، وسنساعدك في تجهيز طلب عرض سعر واضح ومتابعة البحث عن مقدم مناسب؛ لا نعد بتوفر شركة أو سعر أو موعد.
