# Majlis and sofa upholstery — Al Hili

A useful furnishing request starts with verified measurements and an approved sample. A reference picture will not identify construction, installation or delivery requirements. Compare what is included in each quote.

> Taxonomy status: proposed, not active. Editorial guidance does not activate a listing.

## 1. Arabic majlis tailoring

Measure each run, seating depth, back height and cushion count before ordering foam. For the quotation, prepare four-angle photos, seat and cushion dimensions and existing damage; make clear whether the request is for a new item, repair or supply only. Made-to-measure work should not rely on approximate dimensions.

**What the quote should cover:** Ask for a breakdown of fabric, foam, stitching, frame repairs and transport. Identify extras such as disposal of old items, wall repairs and access to upper floors. Agree quantities, samples, payment stages, timing and warranty terms so offers are comparable.

**At handover:** Try the item under normal use. Check finish, dimensions, edges, stability and cleaning access. Photograph any defects before signing off.
