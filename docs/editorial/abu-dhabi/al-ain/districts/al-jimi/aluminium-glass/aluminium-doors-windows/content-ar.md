# أعمال الألمنيوم والأبواب والنوافذ في الجيمي

دليل تحضيري لخدمات الشركات والمنشآت، وليس دليلًا لعمالة فردية أو إعلانًا عن مزود متاح. لا يُفترض تنفيذ أي عمل قبل المعاينة وتحديد المواصفات.

## 1. تصنيع نوافذ الألمنيوم

**متى تحتاج الخدمة ونطاقها:** حدد نوع الفتح والقطاع والعزل والزجاج قبل التصنيع. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** قياس الفتحات عند ثلاث نقاط ومواضع التصريف. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** اطلب عينة القطاع واللون وسماكة الزجاج والملحقات. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** اختبر حركة الضلف وإحكام الإغلاق ومسارات تصريف الماء. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 2. تركيب نوافذ الألمنيوم

**متى تحتاج الخدمة ونطاقها:** افحص استواء الفتحة وسلامة العتبة قبل التثبيت. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** صور جوانب الفتحات وحدد ارتفاع العمل والوصول. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن عدد المراسي وطريقة السد والفواصل وما إذا كان إصلاح اللياسة مشمولًا. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** افحص الاستقامة والتشغيل وعدم وجود فجوات ظاهرة. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 3. تصنيع أبواب الألمنيوم

**متى تحتاج الخدمة ونطاقها:** حدد استعمال الباب داخليًا أو خارجيًا وحركة المرور. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** سجل فتحة الباب والعتبة واتجاه الحركة ومكان القفل. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن مقاطع الإطار وتقوية الزوايا والمفصلات والتشطيب. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** اختبر تطابق الضلفة والقفل وعدم احتكاكها بالأرض. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 4. تركيب أبواب الألمنيوم

**متى تحتاج الخدمة ونطاقها:** راجع جاهزية الأرضية النهائية قبل تحديد منسوب الباب. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** صور العتبة والحائط وحدد قيود الوصول ونوع التثبيت. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** اطلب فصل تكلفة الإزالة والنقل والسد عن التركيب. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** اختبر فتح الباب وإغلاقه وثبات الإطار. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 5. تركيب الشبك

**المعاينة والصور والمقاسات:** قِس كل ضلفة ومكان المسار وموضع المقبض. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.
