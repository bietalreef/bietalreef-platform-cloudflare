# الواجهات والأعمال الزجاجية في الجيمي

دليل تحضيري لخدمات الشركات والمنشآت، وليس دليلًا لعمالة فردية أو إعلانًا عن مزود متاح. لا يُفترض تنفيذ أي عمل قبل المعاينة وتحديد المواصفات.

## 1. تنفيذ واجهات زجاجية

**متى تحتاج الخدمة ونطاقها:** حدد النظام الإنشائي وحركة المبنى ومقاومة الرياح قبل التسعير. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** اطلب رفع الأبعاد والارتفاعات ونقاط التحميل والوصول. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن المخططات المعتمدة والزجاج الآمن والأختام واختبارات التسرب. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** راجع شهادات المواد وفواصل الحركة والتثبيت والفحص المهني. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 2. تركيب الزجاج السيكوريت

**متى تحتاج الخدمة ونطاقها:** حدد موضع الاستخدام وخطر الصدمات قبل اعتماد نوع الزجاج. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** قِس الفتحات والفتحات المطلوبة في اللوح قبل التصنيع. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن السماكة المناسبة والحواف والمشابك وشهادة الزجاج. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** افحص سلامة الحواف وعدم ملامسة الزجاج للمعادن مباشرة. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.
