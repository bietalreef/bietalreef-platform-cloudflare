# تشكيل الحديد والمعادن في الجيمي

دليل تحضيري لخدمات الشركات والمنشآت، وليس دليلًا لعمالة فردية أو إعلانًا عن مزود متاح. لا يُفترض تنفيذ أي عمل قبل المعاينة وتحديد المواصفات.

## 1. تصنيع الأبواب الحديدية

**متى تحتاج الخدمة ونطاقها:** حدد الحماية المطلوبة والتهوية واتجاه الفتح والاستخدام. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** قِس الفتحة ونقاط المفصل والعتبة وموقع القفل. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن سماكات المقاطع واللحامات ومقاومة الصدأ والأقفال. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** افحص الاستقامة واللحام والطلاء والتشغيل. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 2. تصنيع الدرابزين

**متى تحتاج الخدمة ونطاقها:** حدد الموقع الداخلي أو الخارجي وخطر السقوط. يشمل العرض فقط الأعمال والكميات المحددة كتابيًا؛ إزالة القديم أو معالجة العيوب الخفية أو الأعمال المدنية والكهربائية ليست مشمولة إلا بنص صريح.

**المعاينة والصور والمقاسات:** قِس طول المسار والمناسيب ونوع قاعدة التثبيت. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**المواد والمقارنة والاتفاق:** قارن ارتفاع الحماية والتباعد والمرابط والطلاء وفق المتطلبات. اطلب عرضًا يفصل المواد والكمية والتصنيع والتركيب والنقل والضمان ومدة التنفيذ وأي تصاريح لازمة، مع عينة أو رسم معتمد قبل بدء العمل.

**فحص الاستلام:** افحص صلابة الدرابزين وخلو الحواف من النتوءات. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

## 3. تصنيع المظلات

**المعاينة والصور والمقاسات:** ارفع أبعاد المساحة والارتدادات ونقاط التأسيس. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.

**فحص الاستلام:** افحص التثبيت والميل وتصريف المياه وسلامة اللحامات. سجّل الملاحظات قبل الإغلاق النهائي، واطلب إرشادات الصيانة.

**طلب عرض السعر:** صف الموقع في الجيمي وأرفق الصور والقياسات والاستخدام المتوقع، واطلب تحديد ما هو مستثنى. طلب عرض السعر عبر بيت الريف ممكن حتى إن لم تكن شركة منشورة لهذا التخصص؛ لا يُضمن توفر شركة أو سعر أو موعد. الأعمال التي تتطلب تصميمًا أو اعتمادًا أو ترخيصًا ينفذها المختص المؤهل وفق المتطلبات المعمول بها.

**المعاينة والصور والمقاسات:** حدد البحور والارتفاعات والأساسات ومداخل الرفع. أرسل صورًا عامة وتفصيلية وأبعادًا تقريبية، وتُعتمد مقاسات التصنيع بعد رفع الموقع.
