# مراجعة السيراميك والبورسلان — الجيمي

- الحالة: `reviewed_specialty`؛ سبع خدمات شركات ومنشآت بأسمائها العربية المطابقة للمصدر، وسبعة عناوين إنجليزية بالترتيب نفسه.
- أعيدت كتابة كل خدمة بمناسبة الطلب، المدخلات، النطاق والاستثناءات، المقارنة، الاتفاق، الاستلام، وطلب السعر؛ لا يُخلط فحص التوريد باختبار جودة التركيب.
- لا ادعاء بتفعيل الخدمة أو توفر مزود أو سعر أو موعد. المراجعة النهائية للمنطقة ما زالت `in_progress`.
