# الرخام والجرانيت في الجيمي — دليل التوريد والتنفيذ

اختيار الحجر الطبيعي يتطلب اعتماد عينة فعلية، لأن اللون والعروق قد يختلفان بين القطع. هذا محتوى لشركات ومنشآت ولا يثبت توفر جهة أو مادة.

## 1. توريد الرخام الطبيعي

**الحاجة والمعاينة:** في أعمال توريد الرخام الطبيعي جهّز اللون والعروق ومقاس البلاطات والسماكة ومناطق الاستخدام، مع صور الموقع والعينة ومقاسات دقيقة. حدّد مسبقًا إن كانت الخدمة توريدًا أو تصنيعًا أو تركيبًا أو معالجة، لأن كل مرحلة لها معدات ومسؤوليات مختلفة.

**نطاق العمل ومقارنة العروض:** اطلب تحديد نوع الحجر والسماكة والتشطيب ووحدة الحساب والهالك والقص والرفع والتثبيت ومواد اللصق أو المعالجة. لا تعتبر إزالة القديم أو إصلاح القاعدة أو السقالات أو النقل ضمن السعر إلا إذا كُتبت. اتفق على اعتماد عينة وتوزيع العروق وحماية الأسطح ومدة المعالجة وشروط إعادة العمل.

**الاستلام:** افحص توافق العروق والدفعة وسلامة الحواف وعدم وجود شروخ غير مقبولة، وسجّل الملاحظات قبل توقيع الاستلام النهائي. أعمال الواجهات والتثبيت الثقيل تحتاج تفاصيل تصميم واعتماد جهة مختصة، لا الاكتفاء بتقدير بصري.

**طلب عرض السعر:** أرسل الصور والمخططات والكمية إلى خدمة عملاء بيت الريف لإعداد مقارنة بنود؛ لا ضمان لشركة أو سعر أو موعد.
