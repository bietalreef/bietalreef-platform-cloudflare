# تنظيف الواجهات والمواقع في الجيمي — دليل إعداد طلب عرض سعر

يخدم هذا الدليل احتياجات المواقع في الجيمي بمدينة العين دون افتراض توفر شركة بعينها. يجب تحديد نوع الخامة ومواعيد إشغال المكان قبل الاتفاق. هذا مسار شركات ومنشآت، لا قائمة مهنيين مستقلين.

## 1. تنظيف الواجهات الزجاجية

**متى تحتاج الخدمة:** آثار غبار وماء على ألواح زجاجية مرتفعة.

**المعاينة والصور والمقاسات:** صور عامة وتفصيلية للزجاج والارتفاع ونقاط الوصول.

**نطاق التنفيذ والاستثناءات:** تنظيف بمواد لا تخدش الطلاء مع خطة وصول آمن؛ إصلاح الخدوش أو فك الزجاج خارج النطاق.

**مقارنة العروض وبنود الاتفاق:** قارن وسائل الوصول والتصاريح والحواجز وحماية المشاة. وثّق المواد والمعدات وعدد الزيارات والضمانات المحددة وأي رسوم نقل أو إضافات كتابةً.

**فحص الاستلام:** افحص من زوايا إضاءة مختلفة دون هالات أو ضرر للحواف. التقط صورًا قبل العمل وبعده وسجل الملاحظات مع المنفذ.

## 2. تنظيف واجهات المباني

**متى تحتاج الخدمة:** اتساخ الحجر أو الدهان أو الكسوة الخارجية.

**المعاينة والصور والمقاسات:** حدد نوع الكسوة والارتفاع والمساحة وصور التشققات.

**نطاق التنفيذ والاستثناءات:** اختبار ضغط الغسيل والمنظف على جزء صغير وحماية الفواصل؛ ترميم الكسوة ليس تنظيفًا.

**مقارنة العروض وبنود الاتفاق:** قارن معالجة المياه والمواد وحماية النباتات والممتلكات. وثّق المواد والمعدات وعدد الزيارات والضمانات المحددة وأي رسوم نقل أو إضافات كتابةً.

**فحص الاستلام:** افحص ثبات الطلاء وسلامة الفواصل وعدم ظهور خطوط غسيل. التقط صورًا قبل العمل وبعده وسجل الملاحظات مع المنفذ.

## 3. تنظيف المواقف

**متى تحتاج الخدمة:** بقع زيت وغبار في مواقف تستخدمها المركبات.

**المعاينة والصور والمقاسات:** أرسل المساحة ونوع الأرضية وصور المصارف ومواعيد الإغلاق.

**نطاق التنفيذ والاستثناءات:** كنس ومعالجة بقع وغسيل منضبط للمياه؛ إزالة التلوث الخطِر أو إصلاح الأرضية خارج العقد.

**مقارنة العروض وبنود الاتفاق:** قارن خطة تحويل المركبات وحواجز السلامة والتخلص من المياه. وثّق المواد والمعدات وعدد الزيارات والضمانات المحددة وأي رسوم نقل أو إضافات كتابةً.

**فحص الاستلام:** افحص المصارف ودرجة الانزلاق والبقع المتبقية قبل فتح الموقف. التقط صورًا قبل العمل وبعده وسجل الملاحظات مع المنفذ.

## 4. تنظيف المواقع الصناعية

**متى تحتاج الخدمة:** غبار إنتاج أو مخلفات تشغيل حول المعدات.

**المعاينة والصور والمقاسات:** صوّر مناطق العمل وحدد نوع المخلفات ومخاطر الآلات والمساحات.

**نطاق التنفيذ والاستثناءات:** تنظيف مناطق مصرح بها بعد عزل المعدات؛ المخلفات الخطرة تحتاج جهة مؤهلة وترتيبًا منفصلًا.

**مقارنة العروض وبنود الاتفاق:** قارن تصاريح العمل ومعدات الوقاية وإجراءات فصل الطاقة والتخلص من النفايات. وثّق المواد والمعدات وعدد الزيارات والضمانات المحددة وأي رسوم نقل أو إضافات كتابةً.

**فحص الاستلام:** راجع سجل المناطق المنجزة وعدم إعاقة معدات السلامة أو التشغيل. التقط صورًا قبل العمل وبعده وسجل الملاحظات مع المنفذ.

## طلب عرض السعر

أرسل إلى خدمة عملاء بيت الريف صور الموقع والمقاسات والخامات والموعد المرغوب، مع طلب نطاق مكتوب والاستثناءات. يمكن تجهيز الطلب حتى لو لم توجد شركة منشورة؛ لا ضمان لتوفر شركة أو سعر أو موعد. تحقق من التراخيص وإجراءات السلامة المطلوبة.
