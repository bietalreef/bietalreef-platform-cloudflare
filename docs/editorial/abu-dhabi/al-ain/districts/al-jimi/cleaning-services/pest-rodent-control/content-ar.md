# مكافحة الحشرات والقوارض في الجيمي

إذا كنت تطلب شركة لتنظيف أو تشغيل أو مكافحة مشكلة في موقع بالجيمي، حدد المهمة ونوع السطح أو النظام وأوقات الاستخدام قبل مقارنة عروض الأسعار. عدم وجود شركة منشورة لا يمنع إعداد طلب، لكنه لا يعني وجود حجز أو سعر جاهز.

## 1. مكافحة الصراصير

**ما يستحق الفحص أولًا:** وجود الصراصير خلف الأجهزة يرتبط أحيانًا برطوبة أو فتحات لا يصلها الرش السطحي. جهّز صور الحشرات أو آثارها ومواضع الظهور وتوقيت المشكلة ووجود أطفال أو حيوانات، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

**النطاق والاستثناءات:** اطلب تشخيص الآفة ومصدرها وخطة الإغلاق والمنتج المسموح وتعليمات سلامة الأطفال والحيوانات والمتابعة. اطلب بيان المواد والأجهزة ومسؤولية التنظيف والتخلص من المخلفات وما لا يدخل في العقد، ثم قارن آلية المتابعة ومدة تعطيل المكان وليس الرقم النهائي فقط.

**الاستلام:** راجع سجل الزيارة ونقاط المعالجة والإغلاق وتوصيات منع العودة. سجّل بالصور مناطق لم تُنجز أو تعليمات السلامة اللازمة قبل استخدام المكان. لا تقبل ادعاءات تطهير أو سلامة مطلقة دون توثيق مناسب.

## 2. مكافحة النمل

**وصف المشكلة:** تتبع خطوط النمل إلى المدخل أولى من رش مسار واحد ثم إغلاق النوافذ. جهّز صور الحشرات أو آثارها ومواضع الظهور وتوقيت المشكلة ووجود أطفال أو حيوانات، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## 3. مكافحة القوارض

**الحاجة ونوع العمل:** الفتحات حول الخدمات وبقايا الطعام تحتاج سدًا ومراقبة لا سمومًا عشوائية. جهّز صور الحشرات أو آثارها ومواضع الظهور وتوقيت المشكلة ووجود أطفال أو حيوانات، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

**ما يستحق الفحص أولًا:** علامات الجلد وحدها لا تثبت الإصابة؛ يلزم فحص المراتب والأثاث القريب. جهّز صور الحشرات أو آثارها ومواضع الظهور وتوقيت المشكلة ووجود أطفال أو حيوانات، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## 5. عقود المكافحة الدورية

**وصف المشكلة:** العقد يحتاج نقاط رصد وسجلات زيارة وخطة تصحيح لا تكرار الرش بلا قياس. جهّز صور الحشرات أو آثارها ومواضع الظهور وتوقيت المشكلة ووجود أطفال أو حيوانات، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## تجهيز طلب السعر مع بيت الريف

تحتاج مساعدة في اختيار الشركة المناسبة؟ أرسل تفاصيل العمل والصور والمقاسات المتاحة إلى خدمة عملاء بيت الريف، وسنساعدك في تجهيز طلب عرض سعر واضح ومتابعة البحث عن مقدم مناسب. لا نضمن شركة أو سعرًا أو موعدًا، ويجب التحقق من التراخيص والكفاءات اللازمة للأعمال المنظمة.
