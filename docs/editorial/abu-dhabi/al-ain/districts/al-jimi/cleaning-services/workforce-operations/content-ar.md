# خدمات العمالة والتشغيل في الجيمي

إذا كنت تطلب شركة لتنظيف أو تشغيل أو مكافحة مشكلة في موقع بالجيمي، حدد المهمة ونوع السطح أو النظام وأوقات الاستخدام قبل مقارنة عروض الأسعار. عدم وجود شركة منشورة لا يمنع إعداد طلب، لكنه لا يعني وجود حجز أو سعر جاهز.

## 1. توفير عمال النظافة

**ما يستحق الفحص أولًا:** قائمة مهام الوردية والمواد المتاحة تحدد عدد العاملين الواقعي. جهّز عدد العمال والمهارات والمهام والأدوار المطلوبة ومواعيد الوردية ومخاطر الموقع، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

**النطاق والاستثناءات:** حدد جهة التوظيف أو التوريد والإشراف والنقل والتجهيزات وساعات العمل وتغطية الغياب والمسؤولية القانونية والسلامة. اطلب بيان المواد والأجهزة ومسؤولية التنظيف والتخلص من المخلفات وما لا يدخل في العقد، ثم قارن آلية المتابعة ومدة تعطيل المكان وليس الرقم النهائي فقط.

**الاستلام:** راجع الحضور ومطابقة المهارات وتقرير العمل اليومي وحالة الموقع بعد الورديات. سجّل بالصور مناطق لم تُنجز أو تعليمات السلامة اللازمة قبل استخدام المكان. لا تقبل ادعاءات تطهير أو سلامة مطلقة دون توثيق مناسب.

## 2. توفير عمال التحميل

**وصف المشكلة:** وزن الأثاث ومواقع السلالم يحتاج أدوات رفع وعمالًا مدربين بدل الرفع اليدوي الخطر. جهّز عدد العمال والمهارات والمهام والأدوار المطلوبة ومواعيد الوردية ومخاطر الموقع، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## 3. توفير فنيي الصيانة

**الحاجة ونوع العمل:** تحديد كهرباء أو تكييف أو سباكة مهم للتحقق من صلاحية الفني لكل مهمة. جهّز عدد العمال والمهارات والمهام والأدوار المطلوبة ومواعيد الوردية ومخاطر الموقع، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## 7. خدمات الدعم للمشاريع

**ما يستحق الفحص أولًا:** أعمال الجرد والتنزيل وترتيب الموقع تفصل عن تنفيذ فني يحتاج اعتمادًا. جهّز عدد العمال والمهارات والمهام والأدوار المطلوبة ومواعيد الوردية ومخاطر الموقع، مع الإشارة إلى أي مخاطر صحية أو حساسية للخامة أو وجود أشخاص أثناء الخدمة.

## تجهيز طلب السعر مع بيت الريف

تحتاج مساعدة في اختيار الشركة المناسبة؟ أرسل تفاصيل العمل والصور والمقاسات المتاحة إلى خدمة عملاء بيت الريف، وسنساعدك في تجهيز طلب عرض سعر واضح ومتابعة البحث عن مقدم مناسب. لا نضمن شركة أو سعرًا أو موعدًا، ويجب التحقق من التراخيص والكفاءات اللازمة للأعمال المنظمة.
