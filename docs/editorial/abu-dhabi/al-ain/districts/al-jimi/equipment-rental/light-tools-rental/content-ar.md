# تأجير الأدوات والمعدات الخفيفة في الجيمي

معلومات لتجهيز طلب إيجار من شركة أو منشأة، دون افتراض وجود مخزون أو عرض قائم. اختيار المعدة يعتمد على المهمة ومكان التشغيل ومتطلبات السلامة.

## 1. تأجير مولدات الكهرباء

في موقع بلا تغذية ثابتة، احصر أحمال التشغيل والبدء بالكيلوواط وتزامن تشغيل المعدات، وصوّر مساحة وضع المولد ومسار الكابلات والتهوية. لا تختَر القدرة بجمع الأحمال الاسمية وحدها؛ راجع تيارات الإقلاع مع المختص.

**العرض والاتفاق والاستلام:** قارن القدرة الفعلية ونوع المخارج والوقود وساعات التشغيل والضوضاء والنقل والتأريض وفني التوصيل؛ الوقود والكابلات والتوزيع ليست ضمن الإيجار تلقائيًا. افحص التسربات والحمايات وسجل العداد واختبار التشغيل تحت حمل مناسب.

## 2. تأجير معدات التنظيف

لتنظيف أرضيات بعد التشطيب، حدّد نوع السطح ومساحته وطبيعة الاتساخ ومواقع الماء والكهرباء والصرف. أرسل صور البقع والممرات والأبواب حتى تُختار ماكينة غسيل أو شفط تناسب السطح ولا تخدشه.

**العرض والاتفاق والاستلام:** اسأل عن الفرش والوسادات والمواد الكيميائية وخزانات المياه والتوصيل والتدريب؛ العمالة والتخلص من المياه الملوثة خارج الإيجار ما لم يُتفق. اختبر التشغيل والتسريب ونظافة الخزانات وحالة الفرش عند التسليم.

## 3. تأجير ضواغط الهواء

للرش أو تشغيل أدوات الهواء، حدّد ضغط التشغيل وتدفق الهواء المطلوب ومعدل الاستخدام المتواصل وعدد الأدوات. صوّر موقع الجهاز وطول مسار الخراطيم وحدد مصدر الطاقة والتهوية.

**العرض والاتفاق والاستلام:** قارن التدفق عند الضغط المطلوب لا حجم الخزان وحده، وحدد الخراطيم والوصلات والفلاتر ومجفف الهواء والوقود أو الكهرباء. افحص صمام الأمان ومقياس الضغط والخراطيم والتسربات وسجل اختبار التشغيل.

## 4. تأجير العدد الكهربائية

عند تركيب ألواح أو حفر فتحات أو قص مواد، حدّد مادة الشغل وسماكتها وقطر الثقب أو طول القطع ومساحة العمل. أرسل صور المادة ومواقع الكهرباء والغبار حتى لا تُستأجر أداة غير مناسبة.

**العرض والاتفاق والاستلام:** قارن موديل الأداة وملحقات القطع والبطاريات والشواحن ومعدل استهلاك الريش والأقراص؛ لا تفترض شمول المستهلكات أو العامل. افحص واقي القطع والأسلاك والبطاريات والمفتاح والرقم التسلسلي عند الاستلام.

## 5. تأجير معدات اللحام

للإصلاح أو التجميع المعدني، حدّد نوع المعدن وسماكته وطريقة اللحام المطلوبة ومصدر الكهرباء ومكان العمل. أرسل صور الوصلات وبيّن إن كان الموقع مغلقًا أو قرب مواد قابلة للاشتعال.

**العرض والاتفاق والاستلام:** حدّد هل الإيجار يشمل الكابلات ومشبك التأريض والغاز والمنظمات والأسلاك والأقطاب ومعدات الحماية؛ لا يشمل اعتماد اللحام أو العامل تلقائيًا. افحص العزل والتوصيلات والتبريد ووسائل الوقاية، ولا يبدأ العمل دون احتياطات الحريق والتهوية.

## 6. تأجير مضخات المياه

لنزح تجمعات أو نقل مياه موقع، حدّد كمية المياه وارتفاع الضخ والمسافة وقطر الخرطوم وطبيعة الشوائب. صوّر نقطة السحب والتصريف وتحقق من مسار تصريف مسموح قبل التشغيل.

**العرض والاتفاق والاستلام:** قارن منحنى التدفق عند الارتفاع المطلوب والوقود أو الكهرباء والخراطيم والمصفاة والاحتياطي؛ لا تفترض شمول تصريح التصريف أو معالجة المياه. افحص الختم والتسرب والشفط وحالة المروحة وتجربة الضخ.

## 7. تأجير معدات الحدائق

لقص عشب أو تهذيب أشجار أو تنظيف مخلفات حديقة، حدّد مساحة العمل ونوع النبات وارتفاع الأغصان وطبيعة الأرض. أرسل صور الوصول والعوائق لتحديد جزازة أو مقص أو منفاخ مناسب.

**العرض والاتفاق والاستلام:** قارن قدرة المعدة والبطاريات أو الوقود وشفرات القطع والنقل والحماية؛ جمع المخلفات والعامل ليسا ضمن الإيجار تلقائيًا. افحص واقيات الشفرات ومفتاح الإيقاف والاهتزاز وحالة البطارية أو المحرك قبل التسليم.

## تجهيز طلب عرض السعر

قدّم لخدمة عملاء بيت الريف صور موقع الجيمي والمواصفات والمدة والملحقات المطلوبة، مع طلب تحديد رسوم النقل والتأمين والأعطال والإرجاع. المساعدة في تجهيز الطلب لا تضمن شركة أو سعرًا أو موعدًا.
