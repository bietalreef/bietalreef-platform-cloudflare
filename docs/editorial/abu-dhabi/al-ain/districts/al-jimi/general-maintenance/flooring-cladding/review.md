# مراجعة تخصص الأرضيات والكسوات — الجيمي

- الحالة: reviewed_editorial؛ سبع خدمات للشركات كما وردت حرفيًا في شجرة المصدر، مع سبعة عناوين إنجليزية مقابلة وبالترتيب نفسه.
- التغطية: حالات الحاجة، صور ومقاسات، المواد والمعدات بحسب العمل، النطاق والاستثناءات، مقارنة عروض الأسعار، بنود الاتفاق، فحص الاستلام وطلب عرض السعر.
- التمييز: دليل شركات ومنشآت وليس قائمة مهنيين؛ لا ادعاء بوجود شركة أو سعر أو موعد، ولا تفعيل للتخصصات المقيدة.
- أسماء الخدمات: تركيب السيراميك؛ تركيب البورسلان؛ تركيب الباركيه؛ تركيب الفينيل؛ تركيب الإنترلوك؛ تركيب كسوات الجدران؛ إصلاح الأرضيات.
- مطلوب في مراجعة المنطقة النهائية: مطابقة عدد جميع خدمات القطاعات الثمانية وفحص الروابط والتفرّد عبر التخصصات.

## تدقيق اتفاقات التنفيذ — 2026-11-10

- استبدلت سبع جمل اتفاق موحدة بالعربية وسبعًا بالإنجليزية ببنود مستقلة لكل خدمة: عينات البلاط، مناولة البورسلان، رطوبة الخشب، لحامات الفينيل، دمك الإنترلوك، فتحات صيانة الكسوة، وتغييرات إصلاح الأرضيات.
- تمت إعادة قراءة ملفي المحتوى من GitHub بعد التعديل وتطابق النص المحفوظ. يبقى اعتماد المنطقة مرهونًا بجرد جميع التخصصات ومطابقة الخدمات والجودة الفنية.
