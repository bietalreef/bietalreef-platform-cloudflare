## محتوى الخدمة لا المحاور الـ17

المصدر يحتوي 8 قطاعات للشركات والمنشآت، 50 تخصصًا، و434 بند خدمة (بعض الأسماء مكررة عمدًا بين تخصصات مختلفة). احتفظ بأسماء التخصصات والخدمات من الملف حرفيًا، وافصل تمامًا قائمة «المهنيين والحرفيين» عن «الشركات والمنشآت». بعض التخصصات مقيدة أو مقترحة في المصدر، فلا تنسب لها حالة نشر أو اعتماد.

لكل قطاع في منطقة واحدة:
- مقدمة محلية موجزة لا تفترض خصائص غير موثقة للمكان؛ تركيزها على نوع الخدمة، لا السياحة أو مميزات المنطقة العامة.
- عنوان واضح لكل تخصص، ثم كل **خدمة مسماة في المصدر** لها شرح بشري منفصل يوضح متى يحتاجها العميل، حدود نطاقها، المعاينة والصور والمقاسات، مواصفات المواد والمعدات، بنود المقارنة في عرض السعر، وخطوات الفحص والاستلام بحسب طبيعة الخدمة. لا تحول هذه العناصر إلى قالب ثابت مكرر بلا فائدة.
- فروق مهمة بين الخدمات المتشابهة؛ نموذج عملي لتجهيز طلب عرض سعر؛ أسئلة حقيقية متعلقة بالقطاع؛ مصادر حكومية/فنية رسمية عند الإدلاء بادعاء تنظيمي مع تاريخ مراجعة.
- الإنجليزية كتابة طبيعية كاملة مماثلة في التغطية، لا ترجمة حرفية رديئة أو اختصار.
- إذا لم توجد شركة منشورة، فخدمة عملاء بيت الريف ونموذج طلب عرض السعر يتوليان استقبال الطلبات؛ **لا تقول إن الخدمة غير موجودة**. لا تخترع شركات أو تَعِد بتوافر موعد أو سعر أو تنفيذ.
- ممنوع إنشاء 17 فصلًا/محورًا داخل المنطقة، وممنوع نسخ محتوى مدينة أبوظبي أو منطقة أخرى مع تبديل الاسم، وممنوع الحشو «أفضل شركة/أرخص شركة» دون سند.

## التسلسل والتحقق

1. اقرأ هذا الملف، `QUEUE.json`، ملف الشجرة، والمحتوى السابق في GitHub.
2. اختر أول منطقة حالتها `pending` أو `in_progress` أو `blocked`، ولا تقفز فوق غير المكتمل.
3. اكتب محتوى جميع خدمات الشركات ضمن القطاعات الثمانية باللغة العربية والإنجليزية **قدر الإمكان خلال التشغيل** مع الحفاظ على الجودة. إذا تجاوزت المهمة سعة التشغيل، لا تختصر أو تتظاهر باكتمال المنطقة، بل احفظ الملفات المكتملة، وسجّل التقدم، وأكمل المنطقة نفسها في التشغيل التالي.
4. ارفع Markdown ومراجعات التحرير على هذا الفرع فقط. أعد قراءة كل ملف من GitHub للتحقق.
5. حدّث `QUEUE.json`: `completed` فقط بعد إثبات وجود الملفات لكل القطاعات الثمانية وجميع خدماتها في اللغتين، بخلاف ذلك `in_progress` مع ما اكتمل وما بقي، أو `blocked` مع سبب موثق.
6. بعد التشغيل أرسل تقريرًا يذكر المنطقة المنجزة، القطاع والخدمات وأعدادها وروابطها، والتقدم الحقيقي، والمرحلة التالية. لا تدعِ إنجاز منطقة بسبب إنشاء العناوين أو تقرير النية فقط.
7. بعد اكتمال المناطق العشر، لا تعِد إنشاءها، وأبلغ باكتمال المهمة لإيقاف جدولتها.
