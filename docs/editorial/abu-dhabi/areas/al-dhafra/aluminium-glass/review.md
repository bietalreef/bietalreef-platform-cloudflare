# مراجعة تحريرية — ورش الحديد والألمنيوم والزجاج والأخشاب — الظفرة

- التخصصات: 5.
- الخدمات: 56 من 56 بالعربية و56 من 56 بالإنجليزية.
- أسماء الخدمات العربية محفوظة وفق المصدر مع مقابل إنجليزي لكل خدمة.
- التخصيص يراعي اتساع الظفرة والنقل والرفع والقياس الميداني دون افتراض قرب ورشة أو توافر فريق.
- لم تُخترع ورش أو أسعار أو مواعيد أو مخزونات أو موافقات.
- طلب عرض السعر متاح عبر خدمة عملاء بيت الريف عند غياب ورشة منشورة.
- أبواب مقاومة الحريق والزجاج والأنظمة الإنشائية تُحال مواصفاتها إلى مستندات المشروع والجهة المختصة دون ادعاء تصنيف أو اعتماد غير موثق.
- قائمة المهنيين والحرفيين منفصلة.
