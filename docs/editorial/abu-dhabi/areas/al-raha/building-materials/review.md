# مراجعة قطاع مواد البناء والتوريد — شاطئ الراحة

- القطاع: building-materials.
- التخصص المغطى في هذه الدفعة: مواد البناء والتشطيب.
- الخدمات المغطاة: 21/21 وفق ترتيب المصدر.
- تنبيه التصنيف: التخصص موسوم بأنه غير قابل للاختيار حاليًا؛ المحتوى التحريري لا يغيّر التصنيف ولا يفعّله.
- اللغتان: العربية والإنجليزية، مع شرح مستقل لكل خدمة.
- معايير الطلب: المواصفة والكمية والوحدة والدفعة والنقل والتنزيل والتخزين ومطابقة المنتج عند الاستلام.
- لا أسماء شركات أو أسعار أو مخزون أو مواعيد مختلقة.
- خدمة عملاء بيت الريف تستقبل طلب عرض السعر عند غياب مورد منشور.
- الحرفيون منفصلون عن الشركات والمنشآت.
- لا ادعاءات حكومية أو تنظيمية غير متحققة؛ أي اعتماد أو مواصفة ملزمة تُراجع في مستند المشروع ومع الجهة المختصة.
- حالة الدفعة: مكتملة تحريرياً؛ يلزم تدقيق فني ولغوي مستقل قبل النشر.
