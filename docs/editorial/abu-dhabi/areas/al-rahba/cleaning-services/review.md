# مراجعة قطاع التنظيف والتعقيم ومكافحة الحشرات — الرحبة

- تاريخ التحقق: 2026-11-15.
- الحالة: مسودة تحريرية مكتملة، 42/42 خدمة بالعربية و42/42 بالإنجليزية، ضمن 8 تخصصات للشركات والمنشآت.
- أُعيد جلب ملفَي المحتوى من GitHub على فرع المراجعة؛ عناوين الخدمات مرقمة 1–42 دون فجوات أو تكرار أرقام في اللغتين، مع نصوص منفصلة لكل خدمة.
- يرد نموذج طلب عرض سعر لخدمة عملاء بيت الريف حتى عند غياب الشركات، دون اختلاق أسعار أو شركات أو مواعيد أو تراخيص. قائمة الحرفيين مستقلة.
- نطاق هذا التحقق آلي بنيوي (أعداد، تسلسل، وجود النصوص واللغتين)؛ لا يعني اعتمادًا بشريًا للجودة الفنية أو صحة كل ادعاء تنظيمي أو دقة الترجمة. يُطلب تدقيق بشري قبل النشر.
- لا تغيير في taxonomy أو الكود الحي أو النشر.
