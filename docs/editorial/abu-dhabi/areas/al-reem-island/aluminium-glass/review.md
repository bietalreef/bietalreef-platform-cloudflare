# مراجعة قطاع الورش — جزيرة الريم

الحالة `in_progress`؛ 42/56 خدمة بالعربية و42/56 بالإنجليزية، 3/5 تخصصات مكتملة: المطابخ والخزائن والأبواب الخشبية 1–14؛ الأثاث والديكور الخشبي 15–28؛ أعمال الألمنيوم والأبواب والنوافذ 29–42. أُعيد جلب الملفين من GitHub وتحقق تسلسل العناوين 1–42 دون فجوات في اللغتين. المحتوى يوضح النطاق والمقاسات والمواصفات والمقارنة والاستلام؛ قائمة الحرفيين منفصلة، ولا تُفترض شركات أو أسعار أو مواعيد. باب الحريق وزجاج الأمان والأعمال الخارجية تتطلب مراجعة فنية وتنظيمية بحسب المشروع قبل النشر. طلب عرض السعر متاح عبر خدمة العملاء دون شركة منشورة.
