# مراجعة قطاع الأثاث — الوثبة

- الحالة: مسودة مكتملة تحريريًا؛ تحتاج مراجعة بشرية فنية ولغوية قبل النشر.
- 4 تخصصات و24 خدمة في كل لغة، بالترتيب والأسماء العربية المطابقة للمصدر، بما فيها تكرار «توريد الأثاث للمشاريع» في تخصصين مختلفين.
- المحتوى يميز التصنيع والبيع والتنجيد والتوريد؛ لا ينسب توفرًا أو اعتمادًا للتخصصات المقيدة أو المقترحة.
- نموذج طلب عرض السعر متاح دون شركة منشورة، وقائمة الحرفيين منفصلة.
- لا ادعاءات تنظيمية جديدة أو أسعار أو مزودون مختلقون.
