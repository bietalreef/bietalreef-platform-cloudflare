# مراجعة قطاع ورش الحديد والألمنيوم والزجاج والأخشاب — المصفح

الحالة: **in_progress**. اكتمل تحرير تخصصَي «المطابخ والخزائن والأبواب الخشبية» (1–14) و«الأثاث والديكور الخشبي» (15–28)، بإجمالي 28/56 خدمة في كل لغة. أُعيد جلب الملفين من GitHub بعد الرفع وفُحص تسلسل 1–28 ومطابقة أعداد اللغتين. النصوص الجديدة تناقش المقاسات والمواد والتصنيع والتركيب والمقارنة والاستلام وفق نوع العمل، مع فصل الحرفيين عن الشركات ومسار طلب السعر عبر خدمة العملاء عند عدم وجود شركات منشورة. لا توجد ادعاءات عن شركات أو أسعار أو توافر. يلزم تدقيق فني ولغوي مستقل قبل النشر.

التالي: «أعمال الألمنيوم والأبواب والنوافذ»، الخدمة 29 «تصنيع نوافذ الألمنيوم». المتبقي في القطاع 28 خدمة، وفي المنطقة 147 من 434.
