# مراجعة ورش الحديد والألمنيوم والزجاج والأخشاب — المصفح

الحالة: **مكتمل تحريرياً؛ بانتظار المراجعة البشرية**. التخصصات الخمسة حسب مصدر التصنيفات: المطابخ والخزائن والأبواب الخشبية (1–14)، الأثاث والديكور الخشبي (15–28)، أعمال الألمنيوم والأبواب والنوافذ (29–42)، الواجهات والأعمال الزجاجية (43–49)، تشكيل الحديد والمعادن (50–56).

أُعيد جلب ملفَي [العربية](content-ar.md) و[الإنجليزية](content-en.md) من GitHub بعد الرفع؛ كل ملف يحتوي 56 عنوان خدمة متسلسلاً من 1 إلى 56 دون فجوات، مع تغطية المعاينة والمقاسات والمواصفات والتسعير والاستلام وفق كل عمل. لم تُضف أسماء شركات أو أسعار أو ادعاءات اعتماد. الحرفيون منفصلون؛ خدمة العملاء تستقبل طلب السعر دون اشتراط شركة منشورة. أي متطلبات إنشائية أو متعلقة بالزجاج الواقي أو السلامة تحتاج تحققاً فنياً وتنظيمياً قبل النشر.

القطاع التالي: `furniture-decor`، الخدمة الأولى حسب مصدر التصنيفات. المنطقة: 315/434 خدمة لكل لغة؛ المتبقي 119.
