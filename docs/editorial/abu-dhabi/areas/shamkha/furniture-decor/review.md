# مراجعة قطاع furniture-decor — الشامخة

- حالة المحتوى: **مسودة تغطية عددية مكتملة، تحتاج إعادة تحرير محلية مستقلة وتدقيقًا فنيًا ولغويًا قبل الاعتماد**.
- تخصصات الشركات والمنشآت: 4، الخدمات: 24 بالعربية و24 بالإنجليزية، أُعيدت قراءة ملفات GitHub للتحقق من عدد العناوين.
- أُعيد استخدام إرشادات فنية منشورة سابقًا ضمن مسودة بني ياس مع استبدال اسم المنطقة وإضافة سياق الشامخة. **هذا ليس تأليفًا محليًا أصيلًا لكل خدمة ولا يجوز اعتباره جاهزًا للنشر**.
- مراجعة مطلوبة: تطابق أسماء وترتيب الخدمات مع TAXONOMY_SOURCE_AR.md، المضمون بين اللغتين، التفاصيل الفنية والتراخيص حيث تنطبق، وعدم اختلاق مزود أو سعر أو تغطية.
- قائمة الحرفيين منفصلة عن الشركات. نموذج عرض السعر وخدمة عملاء بيت الريف يستقبلان الطلب عند غياب الشركات دون ضمان تنفيذ.
