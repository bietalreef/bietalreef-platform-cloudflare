## ضوابط الملفات

- تحتفظ هذه الملفات بمحتوى **«استكشف هذا التخصص»** الموسع؛ لا تحل محل نصوص «المزيد» المختصرة.
- المحتوى العربي في الملفات مسودات تحريرية، ولا يعني وجود الشركة أو تمكين خدمة أو ترخيص أو نشر تلقائيًا.
- الشجرة المشار إليها في أدلة القطاعات هي مسودة مراجعة، وليست تغييرات منفذة في Supabase.
- النسخة الإنجليزية والصور وربط الصفحات الحية وأعمال SEO النهائية مراحل مستقلة لم تنجز عبر حفظ هذه الملفات.
- **القسم الخامس (الورش):** يحتاج مراجعة واعتماد مستوى المعاينة البصرية بعد الملاحظات السابقة؛ حفظ الملف لا يعني موافقة صاحب المشروع على تصميمه.
- **الأقسام السادس والسابع والثامن:** تم حفظ النسخ المحلية التي عُرضت للمراجعة دون تعديل محتواها أو إعلان اعتمادها.
- لا تدمج هذا الفرع في `master` ولا تنشره على Cloudflare قبل مراجعة المحتوى واعتماد خطة الدمج.
