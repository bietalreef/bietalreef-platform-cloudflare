# صور دليل المقاولات العامة في دبي — حزمة المراجعة

تحتوي الحزمة على 12 صورة أساسية و12 نسخة هاتف، وملف Manifest ثنائي اللغة، وخريطة مواضع الصور، ونسخ المصدر الأصلية. أُعدت للمستودع القائم `bietalreef/bietalreef-platform-cloudflare`، على فرع `assets/dubai-contracting-visuals-20261106`، دون دمج أو نشر.

## الوصول إلى الملفات

- `public/images/uae-2026/sectors/dubai/general-contracting/`: ملفات الموقع الجاهزة، 18 WebP و6 SVG و`manifest.json`.
- `review/index.html`: ملف مراجعة محلي يعرض الصور ووصفها وAlt باللغتين والشروح التعليمية في HTML. افتحه بعد فك ضغط الحزمة مع إبقاء بنية المجلدات.
- `review/contact-sheet.jpg`: معاينة المجموعة كاملة.
- `placement-map.md`: أسماء الملفات وروابط GitHub وربطها بالأقسام والمراجع.
- `quality-report.md` و`validation.json`: نتائج الفحص وحدوده.
- `source/originals/`: 10 ملفات PNG الأصلية: 9 مشاهد أساسية ونسخة غلاف الهاتف المستقلة.
- `source/editable/`: 6 رسوم SVG أصلية وسكربت إعادة بنائها.
- `source/catalog.json` و`source/prompts.json`: البيانات التحريرية وأوامر إنتاج المشاهد باستخدام توليد الصور المدمج؛ تعديل المشهد 12 موثق أيضًا في `company-variation-note.json`.
- `source/references/`: نسخة المرجع التصنيفي المرفق، محفوظة للمطابقة.

ملفات `source` ليست ضمن ملفات الموقع العامة. ملف المراجعة ليس تطبيقًا أو موقعًا موازيًا ولا يتصل بخدمات حية.

## القرارات التحريرية

المرجع المرفق «شجرة بيت الريف: القطاعات والتخصصات والخدمات» مسودة غير مطبقة، وليس دليل مقاولات تفصيليًا. تمت قراءته كاملًا. رُبطت الصور 02–07 بستة بنود في قسمه الأول. الرسوم 08–10 تعتمد أيضًا على النصوص الموجودة فعلًا في `data/uaeSectorGuidesAr.js` و`data/emirateKnowledge.json` و`data/emirateTopicAnswers.js`، وعلى الموجز المطلوب، مع مرجع منفصل لكل صورة داخل Manifest.

صفحة دبي الحالية تعرض عنوان النشاط وغلافًا وشركات ودعم عملاء وأسئلة شائعة ودعوة انضمام الشركة؛ لم تكن تعرض الأقسام الستة أو الرسوم التعليمية بهذا التنظيم وقت الفحص. لذلك تحدد الخريطة مواضع قائمة وأقسامًا مقترحة، ولا تدّعي وجود جميع الأقسام حاليًا.

الحدائق والري والمظلات تتضمن تصنيفات غير قابلة للاختيار وفق المرفق. تجهيز صورها لا يفعّلها للتسجيل أو النشر، ولا يغير معرفاتها أو روابط الشركات.

## ضوابط الدمج في مرحلة لاحقة

1. حافظ على H1 واحد، ثم H2 للمحاور وH3 للتفاصيل. النصوص والأزرار والشروح تبقى HTML.
2. الصور ثابتة التكوين في العربية والإنجليزية؛ اختر Alt المناسب ولا تعكس الصورة أفقيًا.
3. استخدم `picture` للغلاف الرأسي والرسوم المعاد ترتيبها، و`srcset` لنسخ صور التخصصات والتفاعل ذات نسبة 4:3. ثبّت الأبعاد أو نسبة العرض للنسخة المختارة لمنع تغير التخطيط.
4. استخدم تحميلًا عاجلًا للغلاف وحده إذا كان ظاهرًا أول الصفحة، وتحميلًا كسولًا لبقية الصور. لا تحمّل نسختي الهاتف والمكتب معًا.
5. المكوّن الحالي `DirectoryResponsiveImage.js` يفترض عروضًا وأبعادًا محددة تختلف عن هذه الحزمة؛ يحتاج الدمج اللاحق مراجعة مستقلة للأبعاد، ولم يُعدّل هنا.
6. أظهر بجوار المشاهد توضيحًا بأنها مولّدة، ولا تستخدمها في معرض أعمال شركة أو على أنها مشروع موثق. نصوص الإفصاح موجودة في Manifest.
7. احتفظ بشرح مرقم ملاصق للرسوم التعليمية، وجدول HTML قابل للقراءة لمقارنة العروض. بيانات الرسم توضيحية وليست تقييمات حقيقية.
8. مسارات الموقع في Manifest مخطط استخدامها بعد الاعتماد وليست روابط حية مؤكدة. روابط GitHub هي روابط التسليم في هذه المرحلة.
