# تقرير الجودة — ورش دبي

النتيجة: 16 أصلًا بصريًا و16 نسخة هاتف جاهزة لمراجعة الإدماج، غير منشورة. 26 WebP و6 SVG.
الحجم الإجمالي لملفات العرض: 1,145,280 بايت. أكبر ملف: 127,176 بايت.

## المراجعة التحريرية والبصرية

- قُرئ دليل Markdown كاملًا (471 سطرًا) وحُفظ HTML المرجعي. رُبطت الصور بالتخصصات الخمسة و56 خدمة، مع خريطة للمحاور الـ17. لم تُستنتج صلاحية التسجيل من الدليل.
- روجعت مجموعة المقاولات السابقة وmanifest وplacement-map وquality-report وصورة التجميع. لا إعادة استخدام لأصولها أو شخصياتها؛ مشاهد هذه المجموعة مخصصة للتصنيع والتفاصيل.
- فُحصت الصور كاملة، مع التركيز على هندسة الإطارات والأبواب والمفصلات والأيدي والأدوات. جرى تنويع شخصيات ولقطات متشابهة أثناء المراجعة. جميع الشخصيات اصطناعية أصلية، دون مرجع وجه حقيقي أو مخزني.
- الآلات مصورة في سياق توضيحي محافظ: CNC خلف حاجز، معدات قطع خاملة، فحص بوابة دون رش أو لحام. لا يُقدّم المشهد إجراء تشغيل أو شهادة سلامة.
- الزجاج والتثبيت والمفصلات تفاصيل بصرية توضيحية، وليست رسومات تصنيع أو إثبات توافق. لا سماكات أو أحمال أو اعتمادات مختلقة. الأبواب غير موصوفة كمقاومة للحريق.
- الغلاف له تكوين رأسي مستقل للهاتف. بقية الصور مصغرة إلى 600×450 دون حذف موضوعها. الرسوم لها توزيع رأسي/جدول متناسب للهاتف؛ روجعت تصييرات بعرض 390 بكسل. مفاتيح الأرقام والشرح الكامل بالعربية والإنجليزية موجودة في HTML وmanifest.
- الرسوم لا تحتوي JavaScript أو روابط أو مراجع خارجية. المقارنة خانات فارغة وليست تقييمًا لمقاولين حقيقيين. 3D ليس بديلًا عن رسومات التصنيع المعتمدة.

## القياسات والتحقق

اختُبرت أبعاد الملفات وصيغها وفكها وأحجامها وبصمات SHA-256 وتفردها وAlt العربي والإنجليزي وروابط معرض المراجعة المحلية. تفاصيل الاختبارات في validation.json. روابط GitHub والتحقق من تنزيلها في upload-report.md.

الغلاف الأساسي مولد أصليًا بمقاس 1672×941 ثم جُهز إلى 1920×1080؛ لا ادعاء بأنه تصوير أصلي بدقة 4K. الأبعاد الأصلية ونسبة التحويل مسجلة لكل صورة. الضغط WebP بجودة 84 للصور و86 للغلاف.

## حدود المراجعة

الصفحة الحية أعادت HTTP 403 عند محاولة قراءتها. فُحصت بنية المستودع والهوية المرجعية؛ لا ادعاء بإجراء مراجعة بصرية مباشرة للصفحة الحية في هذه الجولة. لم تُجر اختبارات أداء حي أو Core Web Vitals لأن الصور لم تُدمج ولم تُنشر. يلزم اعتماد صاحب المنصة لتوزيع الصور والنصوص والتباين عند الإدماج لاحقًا. التحقق البصري لا يعادل اعتمادًا هندسيًا.

لم يُعدّل محتوى الصفحة أو قاعدة البيانات أو التصنيفات أو صور الشركات أو المجموعات السابقة. لا دمج في master ولا أمر نشر Cloudflare. المصادر خارج public في حزمة التسليم.
